# EEEN3008J-Wireless-FL-Client-Selection

Code and results for the Wireless Federated Learning (FL) Client Selection experiments.

## Repository Structure
- `run_experiments.py`: Script to run experiments and generate results.
- `plot_results.py`: Script to plot Fig 1, Fig 3, and Fig 4.
- `results/`: Contains `raw_results.csv` and `seed_diagnostics.csv`.
- `requirements.txt`: Required Python dependencies.
